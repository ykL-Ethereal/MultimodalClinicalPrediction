# 验证

在安装依赖的环境执行：

```bash
python -B -m pytest -q -p no:cacheprovider
```

自动检查固定数据格式、训练专属标准化、患者划分、标签和时间一致性、特征掩码；四个体征编码器的因果前缀、填充隔离、空序列、梯度；GRU-D 衰减公式和分钟间隔递推；四模型微型训练、最佳权重保存与制品重新加载、跨批大小一致性、独立进程预测、主入口、独立日志与故障日志、重复运行不覆盖、文本切块及本地冻结骨干缓存、评价指标。

集成测试使用相同固定格式的六窗口夹具和本地微型 Bert 权重，避免外部下载；它们验证流程正确性，不衡量正式预测效果。测试产物自动删除。真实包装数据的抽样前向验证与单步梯度检查独立于这些夹具进行，不会修改正式数据或启动完整训练。

完整包校验可执行 `python main.py --validate-only`；其会扫描全部分片和病历。完整训练使用 `python main.py`，默认顺序运行三种基线，可在配置中加入 `grud`。

## 2026-10-24 验证结果

在项目 MultiCP 环境（PyTorch 2.14.1 CPU、Transformers 4.57.6）运行全套测试：50 passed，42.58 秒。集成验证包括四模型各训练一个 epoch、最佳参数与制品重载一致、GRU-D 独立进程预测、默认主入口按配置选择模型。

正式数据包初始化确认 1,459,630 个窗口与 6,735 个当前分片。抽取前 8 个训练窗口，仅用这 8 个窗口拟合临时标准化参数，四种模型分别前向和反向；输入为 20 通道体征及 3,558 维检验，均得到有限输出和梯度。该抽样检查关闭文本分支；文本流程由本地微型骨干测试覆盖。临时标准化未导出，未更改正式数据，也未执行完整训练或全包重新扫描。GPU 路径未验证。

已删除旧测试临时目录、旧演示产物/向量缓存、字节码、构建元数据，以及项目数据副本内的 TTE 迁移备份。删除备份前确认全部当前分片存在且不引用备份，并核对了历史迁移记录中的 80,820 次保留字段 SHA256 检查结果。正式数据当前校验清单见 `data/Mutimodel_data/文件校验和_当前.sha256`；原始交付校验清单保留用于来源审计。
