# 模型说明

目的为固定队列上的研究风险预测。输入为预测时点前包装好的体征、检验、病历与静态资料；目标为数据包已有的 1/2/3/6 小时二分类标签。

体征编码器可选 TCN、LSTM、GRU、GRU-D。其余分支共用；验证 AUPRC 选择模型 epoch，测试集不参与选择。可选概率校准需要验证集内独立患者。

训练结果按编码器及时间分别保存。制品记录骨干权重身份、输入顺序、训练集标准化参数、模型种类与文件校验和。推理按制品重建相同编码器。

限制：窗口前历史缺失会影响 GRU-D 初始状态；观测模式可能反映医疗流程；MacBERT 冻结；输入中的可用性时间仍依赖上游包装质量；当前未完成四模型的完整队列效果对比。不能将测试夹具效果或注意力权重解释为临床有效性。
