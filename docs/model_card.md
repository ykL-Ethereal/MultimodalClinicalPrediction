# 模型说明

目的为固定队列上的研究风险预测。输入为预测时点前包装好的体征、检验、病历与静态资料；目标为数据包已有的 1/2/3/6 小时二分类标签。

体征编码器可选 TCN、LSTM、GRU、GRU-D。其余分支共用；验证 AUPRC 选择模型 epoch，测试集不参与选择。可选概率校准需要验证集内独立患者。

训练结果按编码器及时间分别保存。制品记录骨干权重身份、输入顺序、训练集标准化参数、模型种类与文件校验和。推理按制品重建相同编码器。

限制：窗口前历史缺失会影响 GRU-D 初始状态；观测模式可能反映医疗流程；MacBERT 冻结；输入中的可用性时间仍依赖上游包装质量；当前未完成四模型的完整队列效果对比。不能将测试夹具效果或注意力权重解释为临床有效性。

新增体征单模态模式使用 20 通道、120 分钟窗口，排除检验、病历、年龄及性别。TCN/LSTM/GRU/GRU-D 使用独立分类头；XGBoost 仅支持该模式，将相同预处理数组展平为 2400 维，不提取统计特征。mask 含义沿用原数据，不统一方向。

所有可训练模型均使用既定患者划分和相同预测时距，标准化仅拟合训练集。XGBoost 的早停指标明确采用 sklearn average_precision_score，与项目报告的 AUPRC 口径一致；不以 XGBoost 内置 aucpr 数值混代。验证集选择轮次和参数，测试集只做最终评价。启用校准时沿用患者互斥的验证集分区。

比较时同时报告有效样本集合、无效输入数量、AP、AUROC、Brier、训练/预测耗时及内存。多模态可能接受仅检验或病历可用的窗口，跨模式对比必须另取共同有效窗口或说明覆盖差异。尚无完整队列实验证据证明单模态或 XGBoost 更优。XGBoost 第一版使用 CPU 外存训练；缓存构建及磁盘 I/O 可能成为主要耗时。
